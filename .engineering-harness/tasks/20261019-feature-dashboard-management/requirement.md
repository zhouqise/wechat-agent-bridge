# 管理面板完善需求

任务：20261019-feature-dashboard-management；类型 feature；需求负责人：用户。

## 来源与目标

2026-10-19 用户以六项清单要求完善当前本机管理面板：查看最新日志、清除日志、在按钮下展示当前引擎可选模型、解释项目切换、页面新增用户、页面更换认证和 API 地址。沿用用户选择的对话需求基线。此后用户明确：“继续只读环境变量，页面仅修改认证方式、变量名和 API 地址”。

目标是减少终端往返，同时让当前用户、引擎、目录和操作结果在页面上清楚可见。日志与模型结果互不覆盖，用户切换时不显示上一用户的结果。

## 已确认行为与边界

- 日志应显示当前所选用户最新内容，可从页面清除日志；清除不删除配置、绑定、会话或工作文件。
- 点击可用模型，在按钮下展示当前引擎返回的可选模型；不可将备用别名或推测值冒充服务商授权清单。
- 说明项目与工作目录的关系，简化重复入口，保留已登记项目和目录会话恢复。
- 页面提供新增用户与微信绑定流程，沿用现有多用户独立工作区、绑定和会话；不覆盖同名用户或自动改绑已有账号。
- 页面可为 Codex 和 Claude 分别更改认证方式、密钥环境变量名和 API 地址；只显示变量是否存在，不读取返回、接收或保存密钥值。local 认证使用已有 CLI 登录。
- 用户随后明确选择按认证配置隔离会话：认证方式、API 地址或密钥变量名变化后，新配置从新会话开始；切回旧配置恢复原会话，旧上下文不自动发送到新接口。
- 本机管理面板的鉴权与来源校验、多用户隔离粒度、审批和任务执行语义保留。更改认证不能中断执行中的任务。

## 可观察验收

追加日志后页面能看到最新内容和更新时间；清除只作用于选定用户，新日志可继续写入。模型列表出现在模型区域，明确引擎和查询失败/不可列举状态。目录列表显示名称和路径。创建用户后能在页面完成二维码绑定，失败可重试，重复名称不会覆盖。修改认证时错误输入保留旧配置，密钥不出现在响应、页面或日志中；非目标用户不受影响。

## 所有权与假设

目标仓库 zhouqise/wechat-agent-bridge 拥有 dashboard、用户创建、微信扫码、引擎配置全部相关能力，基线 0ed32dc1dac1f51acf5f07c7b4df4d447663f6f1。无需修改第三方 CLI 或微信服务。已确认环境变量策略；页面具体操作、清除范围与保存生效流程在设计中提出，待统一方案确认。真实微信扫码、账号登录或真实密钥不代替用户操作；自动化使用临时数据和模拟服务。
